# 实际代码算法：从输入图像到独立解码，思路一与思路二逐步说明

版本：AIGI01 v1 研究实现。本文描述当前代码真正执行的设计，不把未运行的实验写成结论。所有数值默认值均可在 `aigi/config.py` 和相关模块找到；改变算法默认值后需要新实验、新 checkpoint 和新结果标签。

## 1. 先理解四个不同的任务

**训练**：给模型看大量原图，用原图和重建图的差异更新可训练参数。训练可以使用原图、教师和目标标签。

**编码**：把一张原图转换为有限长度的字节流。编码器可以看原图和 prompt，但不能把某张未计费的内部地图暗中留给解码器。

**解码**：只读取字节流、相同模型和相同程序，输出重建图。默认 prompt 已在字节流内。解码器不能读取原图、教师缓存、编码器的 S/c/e/m 地图。

**评测**：重建完成后，评测器才拿原图来计算 PSNR、LPIPS 等。评测器可读原图，不代表解码器可以读原图。

代码中 `CodecSession.encode_file(image_path, ...)` 接受原图，`CodecSession.decode_file(input_path, ...)` 没有原图参数。这是本实现的端到端通信边界。

## 2. 模型组成与符号

原图记作 x，大小为 H×W，共三个 RGB 通道。H、W 是原始像素尺寸。B 是一个 batch 中的图片数；真正写码流时 B 固定为 1。C 表示当前特征的通道数，不是图片宽度。

p 是普通文字 prompt。原始 AI 图像数据中有生成提示词时保留；没有时可以用 BLIP 为图像产生替代描述。替代描述会被标记来源，不能称为原始生成提示词。

E_DC 是 DiT-IC 使用的冻结 DC-VAE 图像编码器。它把原图压缩到较小的连续特征网格。E_ELIC 是冻结 ELIC 辅助图像编码器，提供另一组特征。g_a 是原 DiT-IC 的主分析变换，把两路特征融合为待编码主潜变量 y。

h_a 是超分析变换，把 y 转成较小的超潜变量 z。h_s 是超合成变换，把量化后的 z 恢复为预测 y 概率分布的基础信息。为了避免与最终生成 latent 混淆，下面把教师中的干净 latent 写作 u0，生成器最后得到的 latent 写作 u_hat。

C=320 是主潜变量 y 的通道数。主潜变量的空间步长为 64；超潜变量空间步长为 256。DC-VAE latent 的通道数为 32，空间步长为 32。

对一张 256×256 图，典型形状依次是：

| 内容 | 张量形状 |
|---|---|
| 输入 RGB x | 1×3×256×256 |
| DC-VAE latent u0 | 1×32×8×8 |
| ELIC 辅助特征 | 1×320×16×16 |
| 主潜变量 y | 1×320×4×4 |
| 超潜变量 z | 1×160×1×1 |
| 主变量重建 q_hat | 1×320×4×4 |
| 生成器输入 mean、log-variance、res | 各为 1×32×8×8 |
| 潜变量 prompt 特征 | 1×320×8×8 |
| 对齐后的 latent prompt | 1×77×2304 |

一个 spatial token 指网格上的一个位置 i，并非一个 RGB 像素。老师的 8×8 图和熵模型的 4×4 图分辨率不同，代码用双线性插值进行对齐，不声称两者天然一一对应。

## 3. 固定后的设计决策

本实现只保留一条明确主路径：冻结 SANA 教师，Gemma2 文本特征，学习 token 权重，S/c/e 地图蒸馏，编码前 UGAQ 缩放，四组因果文本熵条件，流匹配几何的局部 SNR 时间场，残差局部归一化调制，以及三次网络计算的双路引导。

不会融合通用人脸或渲染文字检测先验，不提供手工 token 权重，也没有“把码率用在某个指定物体上”的控制入口。beta 是整个实验的固定系数，不是逐图片人工调优权重。没有思路三，也不做 prompt VQ。

DiT-IC/SANA 使用的是速度场形式，不能直接把 SD 的 epsilon 预测公式照搬进来。下面明确写出速度、噪声、时间与 SNR 的转换。

## 4. 文本如何进入网络

代码：`aigi/text.py`。

文本编码器和 tokenizer 来自相同 SANA 快照。tokenizer 将 p 转为 token ID、有效位 mask；mask=1 表示有效 token，0 表示 padding。文本编码器输出 T，形状是 B×77×2304，77 是固定文本长度，2304 是每个 token 的特征维数。

文本超过 77 tokens 会按 tokenizer 规则截断；码流仍存完整原始 UTF-8 字符串，因此文字比特不会因为网络截断而漏计。本文使用直接 prompt 编码，没有加入一个未记录的“复杂指令模板”。空条件使用真正空字符串经过相同文本编码器得到的 T_empty，不是全零向量。只有不使用外部文本的 `ditic` / `cadc_style` 路径使用占位张量，且不把它们作为真实文本输入。

文本编码器冻结且在 CPU FP32 执行，结果转移给需要它的设备。文件、配置和文本长度参与 fingerprint，解码时要求一致。

## 5. 教师目标怎样计算

代码：`aigi/teacher.py`，仅训练准备时使用。

### 5.1 加噪并匹配流模型的几何

u0=E_DC(x)×s_vae，其中 s_vae 是 DC-VAE 配置中的 scaling_factor。它把特征幅度变到 SANA 约定的尺度；解码时会除回来。

ε 是与 u0 形状相同、均值 0 方差 1 的高斯噪声。t 是 0 到 1 之间的连续流时间；t=0 靠近干净图，t=1 靠近纯噪声：

u_t=(1−t)u0+tε。

如果把干净 latent 的参考方差视为 1，这条插值的几何信噪比是 γ=((1−t)/t)^2。令 λ=log γ，得到：

t=sigmoid(−λ/2)=1/(1+sqrt(γ))。

这里 λ 是教师积分的 log-SNR 变量；配置的 `rate_weight` 是率失真权重，两者不是同一个参数。q 是质量点编号 1、2、3、4。积分上界按 q 固定为 −1、0、1、2，下界固定 −6，在区间内均匀取 8 个 λ 节点。此 q 到积分上界的表是本工程明确选择的设计，不是已经实验证明最优的表。

### 5.2 速度预测转为噪声预测

SANA 预测 v_hat，目标速度是 ε−u0。由上述插值可推出：

ε_hat = u_t + (1−t)v_hat。

对同一 u_t、同一 ε 分别运行真实 prompt 和空 prompt 的 SANA，得到 ε_hat_p、ε_hat_empty。以共享噪声作配对比较，减少“噪声抽样不同”给两者差异带来的干扰。

每个 λ 节点取 2 个噪声样本，先对通道求均方误差，再对 2 个样本平均。8 节点×2样本×2条件，共 32 次 SANA DiT 前向；不是 1 次，也不是训练每个 step 都做 32 次。

### 5.3 c 与 e 是什么

E_p(i,λ) 是位置 i 的条件噪声预测均方误差，E_empty(i,λ) 是空条件误差。固定用梯形积分：

c(i)=0.5∫ E_p(i,λ)dλ，

e(i)=0.5∫[E_empty(i,λ)−E_p(i,λ)]dλ。

c 非负，表示在这组有限噪声尺度下，给了文本之后仍不容易预测的部分。e 保留正负号：正值表示文本改善预测，负值表示文本在该位置使预测更差；不能把负值偷偷裁成 0。

**这两个量在本实现中是有限区间、有限采样、冻结代理模型上的能量指标，不是精确条件熵或精确互信息。** 使用一个 SANA 教师分析 Stable Diffusion、SDXL 或自然图像，不等于拿到了这些图真正的生成噪声、原始 latent 或原生成器。不能把代理误差解释成已知真实信息量。

### 5.4 重要性 S 与 w

在 SANA 第 4、11、18、25 个 transformer block（代码索引 3、10、17、24）的 cross-attention 中，读取真正的 Q、K。Q 是图像查询，K 是文本键，计算有效 token 上的 softmax(QKᵀ/sqrt(d))，然后平均注意力头、层、噪声和时间节点，得到 A_k(i)。k 是文本 token 编号。

N 表示按每张图、每个通道做空间 min-max 归一化，范围 [0,1]。所有位置完全一样时，返回 0.5，而不是把无信息地图误判为全部不重要。

学生使用一个 `2304→128→1` MLP 预测 token 分数，经过有效 token softmax 得到 ω_k，且 Σω_k=1。最后一层零初始化，因此起点是有效 token 等权，而不是人工偏好某个词。

S(i)=N(Σ_k ω_k N(A_k(i)))，

w(i)=0.1+0.9·S(i)^2。

S 是语义重要性图，w 是用于分配和损失的保护权重。0.1 是最低保护，不让任何区域权重变成 0；平方提高高重要性和中低重要性之间的对比。教师缓存使用等权 ω，学生在端到端训练中学习自己的 ω；额外 0.001 权重的均匀先验 KL 项减轻权重塌缩。

## 6. 教师如何变成可运行的学生

代码：`aigi/semantic.py` 的 MapPredictor，`aigi/losses.py` 的 map_loss。

真正编码时不能为每图再调用 32 次教师，也不能要求解码器获得教师的原图。因此用两个独立学生：编码学生输入连续 y 和文本；解码学生输入已恢复 q_hat 和文本。

学生先对图像特征做 3×3 卷积与 SiLU，再用文本 cross-attention 残差融合。图像通过 1×1 卷积产生 64 维查询，文本通过线性层产生 64 维键，两者点积除以 8，softmax 后得到每个位置对各 token 的注意力。TokenWeights 模块将其汇总为 S、w。另一路拼接常数质量图 q/4，经卷积得到 c 和 e；c 使用 softplus 保证非负，e 不加正值限制。

学生不是重新计算真实 SANA 每层注意力，而是学习逼近上述教师目标。蒸馏损失是：S 的 L1，加 log(1+c) 的 L1，加 asinh(e) 的 L1，再加 token 权重弱 KL 先验。对 c/e 进行变换是为了避免较大能量量纲压过 S。地图插值到学生网格后比较。

`stage=maps` 时冻结其余模型，只训练这两个学生。完整 codec 阶段则允许学生与压缩器联合优化。编码、解码学生不共享参数，且解码学生绝不读取编码学生输出。

## 7. 思路一的编码过程

代码：`aigi/entropy.py`、`aigi/semantic.py`。

### 7.1 图像准备与两路特征

打开图像，处理 EXIF 方向并转换 RGB。每个 uint8 值 a 映射成 a/127.5−1，使输入范围为 [−1,1]。推理时只在右边和下边做边界复制 padding，使尺寸成为 256 的倍数，不缩放原图；原始 H、W 写入头部。

由冻结 DC-VAE 和冻结 ELIC 得到两路特征，再送入原主分析变换 g_a，得到 y。图像编码器冻结不意味着主压缩器不训练：g_a、h_a、h_s、概率上下文、合成变换等在 codec 阶段仍可更新。

### 7.2 先生成超潜变量，再估计缩放

z=h_a(y)。训练前向用 STE 近似量化；真实编码使用 EntropyBottleneck.compress，随后编码端马上解回 z_hat。这样编码端与解码端预测后续概率时使用相同已量化信息。

hyper=h_s(z_hat)。纹理控制网络对 y−hyper 做 `3×3 Conv→SiLU→1×1 Conv`，输出：

m_texture=1+softplus(f_texture(y−hyper))。

m_texture 越大，编码前信号幅度越低。这里“纹理不确定性”是网络学习的残差代理，不是调用一个外部纹理分类器。

将学生 S、log(1+c)、asinh(e)、q/4 四张图拼接，经卷积得到：

δ=0.5 tanh(f_delta([S,log(1+c),asinh(e),q/4]))。

δ 是有界修正项，范围 [−0.5,0.5]，最后一层零初始化。最终：

log m=clip(log m_texture−0.5 log w+δ,0,log 16)，

y_bar=y/m。

因此 m 在 [1,16] 内。相同纹理估计下，w 高的位置 m 较小，更少削弱信号；w 低的位置更依赖生成。m 是空间单通道图，广播到全部 320 个主通道。

### 7.3 为什么解码不乘回 m

本设计固定采用 CADC 式“编码前缩放，解码不逆缩放”的路线。解码得到的是 y_bar 所对应的量化表示，不是先还原 y 的常规可逆增益控制。

m 依赖原图，不在码流内，也不传给解码器。如果解码时再乘 m，就必须额外传它或从已编码变量严格重建它，本版本没有这样做。后续合成变换和生成器经过训练，直接消费受调制的 q_hat。这是有损生成压缩的设计选择，不是遗漏了逆运算。

### 7.4 四组因果熵编码

原 DiT-IC 的四组 mask M0…M3 将通道和 2×2 空间模式交错分组，每个元素恰好属于一组。它不是简单从左到右逐像素编码。本工程复用原 mask 实现。

第 k 组的 base 起初为 hyper，后续被已经解码的组逐步替换。经过原 adapter_in 与共享 g_c 得到上下文；思路一启用一个额外文本 cross-attention 残差，再送入原 adapter_out，输出熵模型均值 μ_k 和尺度 σ_raw,k。

有效 σ=max(σ_raw,0.11)，使用 CompressAI 的同一个 lower-bound 模块。注意 σ 是标准差，不是方差；和后面生成 latent 的 log-variance 不是同一张图。

该组整数符号为 n_k=round(y_bar−μ_k)，只取 M_k 指定的位置。真正 rANS 编码使用由 σ 选出的 CDF 索引、整数符号及相同概率表。编码/解码辅助函数复用原 DiT-IC 实现。

解码出整数后先构造 q_k=n_k+μ_k，再加入原 LRP 修正：

q_k ← q_k + 0.5 tanh(LRP_k([q_k,base])·M_k)。

LRP 是已解码上下文的确定性修正，没有读取未来符号。随后 base←base·(1−M_k)+q_k，为下一组提供上下文。

顺序固定为 0→1→2→3。解码端每次预测 μ、σ 时只需要 z_hat、先前组和文本，绝不访问未解码 y。四组相加得到 q_hat。

## 8. 码率分配的 water-filling 辅助目标

代码：`waterfill_target` 与 RateDistortionLoss。

每个主变量元素的估计比特是 −log2(probability)，对通道求和，得到位置 i 的 r_i。B_bits 是当前图所有 r_i 的总和，使用 detach，即不让目标本身通过预算反向追逐网络。

定义 a_i=0.5 log2 w_i+c_i/ln2。寻找阈值 τ，使：

r_star,i=max(a_i−τ,0)，且 Σ_i r_star,i=B_bits。

τ 用 48 次二分法求解。预算为 0 时目标全部为 0。训练惩罚 mean(|r−r_star|)/320，默认系数 0.01；在训练前 10% 步数线性升到完整系数。

由于 c 是代理能量，这里是明确的启发式分配监督，而不是严格率失真定理推出的精确最优解。不要把 r_star 的值当作真实码流每个位置的可独立测量比特；rANS 本身有联合编码开销和概率表离散误差。

## 9. 实际字节流里有什么

代码：`aigi/bitstream.py`。

物理顺序是：8 字节 magic/version，4 字节大端 JSON 头长，JSON 头，zlib 压缩的 UTF-8 prompt，主 rANS 字节，超先验字节，32 字节 SHA256。头部记录方法、质量点、原始/补齐尺寸、超变量形状、模型/文本指纹、prompt 哈希、长度和数值运行时标识。

物理存放顺序不等于解码计算顺序。解析器根据长度切出两个字节段；神经解码先解超先验，再解主变量。

总 bpp=整个 .aigi 文件字节数×8/(H×W)。同时记录主/超 payload、prompt 和 framing 的分项 bpp。分母使用原始尺寸而不是 padding 后尺寸。即使 baseline 不用文本，统一封装里也有空字符串的 zlib 字段开销。

输入校验包括 magic、长度、最大尺寸、字段集合、SHA256、prompt 解压上限和 fingerprint。不匹配立即失败。模型不存进每张图的码流，属于所有方法共享部署成本；它的哈希用于核对版本。训练 checkpoint 与源代码都会影响模型 fingerprint。

真实熵路径固定 CPU FP32、单线程编码和解码，图像特征提取与生成保留在 GPU。这样降低不同 GPU 浮点误差导致概率索引不一致的风险，但不能据此声称已经证明跨所有 CPU 架构的字节可移植性。迁移服务器必须验收。

## 10. 解码端先恢复四种 DiT-IC 条件

通过第 7.4 节相同的四组因果顺序恢复 q_hat，再运行原合成网络：

mean=g_s(q_hat)，res=g_aux(q_hat)，latent_prompt=g_prompt(q_hat)。

原 variance 合成支路接收各组熵尺度对应的原始 raw-scale 张量，输出 log_variance。这里的 mean 是生成器输入特征，不是熵模型 μ_k。两者在代码里都可能含有 mean 字样，论文与解释必须区分。

latent_prompt 先池化成固定 48 个 token，再和可学习 pattern token 拼接，并经原 LatentConditionAlignment MLP 变成 77×2304 的压缩内容条件。此条件全部由 q_hat 确定，不另收 prompt 字节。

原 `ditic` 路径仅使用 latent prompt 与原 variance-guided 单步解码。`idea1` 在保持原单步更新公式时加入真实文本与 latent prompt。`idea2/joint` 则继续执行下面的局部时间场。

## 11. 思路二：只靠可解码信息构造生成强度

### 11.1 熵矩的 SNR 代理

代码：`local_snr`。

解码四组时已经算出的 μ、有效 σ，在 LRP 修正之前记录。把当前符号分布近似为高斯，其二阶矩是 μ²+σ²。量化步长 Δ 固定为 1，均匀量化误差参考方差为 Δ²/12=1/12。因此定义：

SNR_hat(i)=(1/C)Σ_c(μ_c,i²+σ_c,i²)/(1/12)。

这对应 CADC 讨论的受调制信号功率/量化噪声参考方差，不是“μ²除以σ²”的另一种指标。由于 μ、σ 已针对 y_bar 建模，**不能再除一次 m²**。σ² 在这里计入信号分布的二阶矩，而不是作为需要消除的独立噪声。

必须承认这是局部高斯近似的统计代理，不是已经测得的真实重建误差 SNR。原 CADC 的推导不自动证明这个跨 320 维熵 latent 到 32 维 SANA latent 的映射精确成立。本实现把 SNR 图插值到生成网格，并通过训练校准。

### 11.2 语义保护、残差修正与时间

解码学生读取 q_hat 和 p，得到 w_dec。rho 网络的输入是 [log(1+SNR_hat),w_dec,beta,q/4]；beta 默认 0.5，控制重要区域受到的额外保护，整场实验固定。输出：

rho=0.25 tanh(f_rho(...))。

rho 范围 [−0.25,0.25]，最后一层零初始化。时间图定义为：

logit(t_i)=−0.5 log SNR_hat(i)−beta(2w_dec(i)−1)+rho_i，

t_i=clip(sigmoid(logit(t_i)),0.02,0.98)。

SNR 高时 t 小，模型更保守；重要性高时第二项更负，进一步减小生成强度。这里只固定了算法方向，没有保证每个样本都获得更好重建。

`snr_time=false` 使用整图平均 SNR 代替空间变化；`semantic_time=false` 令时间偏置系数为 0；`time_residual=false` 令 rho=0。这三个消融的职责不同，不互相替代。

### 11.3 局部时间怎样进入 DiT

SANA 原接口只接收每张图一个 timestep，不能仅传一个 H×W 张量就宣称模型支持空间时间。本实现保留其原全局 timestep，取 1000×mean(t_i) 再乘模型配置的 timestep_scale。

同时给每个 transformer block 的 norm1、norm2 增加作用于当前前向的局部残差仿射。每个位置的输入是 [logit(t_i),beta,q/4]，经 `3→64→2D` MLP，其中 D 是该 block 隐藏通道数，输出 scale 与 shift：

h_new=(1+0.25 tanh(scale_i))·h_norm+0.25 tanh(shift_i)。

这些新层最后一层零初始化，起点是恒等映射。原 SANA 的全局归一化调制仍存在，所以它是“额外的局部调制”，不是从头替换整个 AdaLN。hooks 在一次 forward 的 finally 中移除；训练关闭 gradient checkpointing，防止反向重计算阶段丢失这些 hooks。

这是一种明确的局部时间条件化实现，但不能把它等同于一个已经严格求解了任意异步 token diffusion 方程的采样器。

### 11.4 双路引导：三次前向而非一次

所有分支都使用同一 mean 输入和同一时间图。定义：

v00：空文本、不附加 latent prompt；

vp0：真实文本、不附加 latent prompt；

vpy：真实文本，加解码得到的 latent prompt。

它们不是三次从纯噪声开始生成的独立图像，也不是没有图像信息的真正无条件生成，因为共同输入 mean 本身已包含码流信息。

令 ζp=1+t(1−w_dec)，ζy=1+w_dec·SNR_hat/(1+SNR_hat)，其中 ζp、ζy 是逐位置引导系数。最终速度：

v=v00+ζp(vp0−v00)+ζy(vpy−vp0)。

低保护且生成强度大的位置会增大文本引导；已传信息可靠且重要的位置会增大内容条件引导。默认推理 NFE=3，即调用 DiT 三次。关闭 `dual_guidance` 时只算 vpy，NFE=1。

训练为降低计算量采用一次分支前向：独立以 10% 概率丢弃文本条件（按样本），以 10% 概率丢弃 latent prompt（按 batch）。所以“关闭双路引导”的消融改变的是推理公式；同一 dropout 训练目标保留。不要声称它在训练时也减少了从 3 到 1 次前向，因为训练本来就是 1 次。

### 11.5 从速度到最终图像

u_hat=mean−t·v+res。

随后运行 DC-VAE 图像解码器：x_hat=decode(u_hat/s_vae)，裁剪到 [−1,1]，去掉右下 padding，映射到 [0,255]，round 后存成 RGB PNG。

`res` 是原 DiT-IC 辅助残差分支；保留它意味着新时间场不是简单的原始扩散采样公式。最终质量取决于联合训练，不应把一个小例子的代数正确性当成模型有效性证据。

## 12. 训练究竟更新什么，如何保存恢复

代码：`aigi/train.py`、`aigi/checkpoint.py`。

默认使用官方 merged DiT-IC 权重初始化原骨干，再为 DiT 与 DC-VAE 解码器添加新的 LoRA；编码器和 ELIC 冻结。主压缩器、latent prompter、启用的学生/控制/条件模块可训练。新 LoRA 默认 VAE rank=64、DiT rank=128；rank 是低秩更新的中间维数，越大表示更多可训练自由度和资源消耗，不是质量必然提升的保证。

训练使用真实量化值的 STE 前向，反向对 round 采用恒等梯度。概率 likelihood 用于估算比特，而训练每一步不运行真实 rANS。真实字节数只在推理编码时取得。

每个 optimizer step 的顺序是：取 batch，读取已验证的教师缓存，图像前向，计算损失，除以 accumulation 后反向，累积完成后裁剪梯度范数到 4，更新主 AdamW，再更新熵瓶颈 quantiles 的辅助 Adam。quantiles 是辅助概率分位点参数，其辅助目标用于建立可用 CDF。DDP 中该辅助梯度单独 all-reduce。

主学习率默认 1e−4，辅助学习率 1e−3。默认主优化器为 AdamW，betas=(0.9,0.999)，weight_decay=0.01；
在整个阶段完成 50%、80%、90% 时，主学习率每次乘 0.5。配置中的 optimizer、weight_decay、lr_gamma 可以显式改变这些选择。
这是 V2 的明确实现，不代表其他未公开的作者训练细节已逐项复现。
GAN 默认使用自适应系数：gan_weight × clamp(||∇θ D||₂ / (||∇θ L_G||₂+1e−4),0,10⁴)，
θ 固定取原 codec.aux.block 最后卷积的权重。该系数 detach 后加入生成器总损失，不对梯度范数本身求二阶导数。
gan_mode=fixed 是显式对照，而不是默认。

完整损失是：

L = D_weighted + rate_weight·(R_y+R_z+R_prompt) + 0.1 L_SD + distill_weight·L_maps + waterfill_weight·anneal·L_WF + GAN 项。

D_weighted 包含按 w 归一化的 RGB MSE、按 w 归一化的空间 LPIPS，以及全局 DISTS。默认 LPIPS 系数 1，DISTS 系数 0.2。DISTS 输入为 [0,1]，LPIPS 输入为 [−1,1]；不伪造一张并不存在的逐像素 DISTS 图。

weighted_mean 对误差乘 w，再除以权重和及误差通道数；不是把权重越大、图像越大直接变成越大的总 loss。R_y、R_z 是每个原训练像素的估计比特；R_prompt 使用 zlib 后真实 prompt 字节数。训练不把头部与 SHA256 常数放入可微目标，但推理总 bpp 一定包含它们。

L_SD=0.05 mean(ReLU(0.5−cosine(u_hat,u0)))，用于保留原 latent 自蒸馏约束。GAN 采用三层 PatchGAN 和 hinge 判别器损失。V2 对生成器所有累积 microbatch 分别保存 detach 的真图/假图，
判别器在同一组 microbatch 上按 accumulation 归一化累积梯度后更新一次。它不是“只用最后一个 microbatch”。
分批的 BatchNorm 统计也不等于把全局 batch 一次拼接后的统计；各对照必须使用相同 accumulation。

EMA 是可训练参数的指数滑动平均，默认衰减 0.999；推理 `--ema` 选择它，编码/解码必须一致。checkpoint 保存模型、主/辅助优化器、判别器、判别器优化器、EMA、step、配置与每个 rank 的 Python/NumPy/Torch/CUDA RNG 状态。精确恢复要求卡数、训练预算、采样规则和配置一致。

当前训练裁剪是确定中心裁剪，小图先复制边界；没有随机裁剪或翻转。因此教师缓存与训练图保持一致，但这与原训练数据增强协议不同。验证 smoke 仅取一张裁剪图，最终结果必须通过完整测试集真实编码/解码生成。

## 13. 一个能亲手算的数值例子

运行：

```bash
python aigi_scripts/numerical_example.py
```

以下输入是为解释公式人工指定的标量，不是声称训练好的神经网络输出这些值，也不是完整 RGB 图像的模拟压缩结果。

设一个位置 S=0.6，则 w=0.1+0.9×0.36=0.424。纹理控制输出 m_texture=2，修正 δ=0，于是 m=2/sqrt(0.424)=3.0714755。

该通道 y=2.8，所以 y_bar=0.9116139。熵模型给出 μ=0.2，σ=0.3，整数 n=round(0.9116139−0.2)=1。解码端读到整数 1 后加均值，得到 1.2；设该组 LRP 修正为 0.02，得到 q_hat=1.22。解码过程没有 m，也没有再乘 3.0714755。

为简化通道平均，假设该位置各通道具有相同 μ、σ，则 SNR_hat=(0.2²+0.3²)×12=1.56。设解码学生同样得到 w_dec=0.424，beta=0.5，rho=0：

logit(t)=−0.5 ln(1.56)−0.5(2×0.424−1)，因此 t=0.4634794。

ζp=1.2669642，ζy=1.2583749。设三分支预测分别为 0.1、0.3、0.4，则最终 v=0.4792303。再设生成输入 mean=0.8、res=0.05，得到 u_hat=0.8−0.4634794×0.4792303+0.05=0.6278866。

下一步必须把完整 32 通道 latent 张量交给真实 DC-VAE 解码器，不能从一个标量 0.6278866 凭空写出一幅“重建图”。

同一脚本还给出四位置 water-filling：w=[0.1,0.424,0.829,1]，c=[0.2,0.5,1.2,0.8]，总预算=2 bit。二分求解得到约 [0,0,1.2209001,0.7791001]，总和因 FP32 舍入约 2.0000002。它只是预算监督目标，不是 rANS 对四位置独立输出了这些小数字节。

## 14. 方法开关与原始构想之间的关系

`ditic`：原图特征、原四组熵模型、原 latent prompt 和原 variance-guided 更新；不消费外部文本。统一训练器和统一码流封装的差异必须注明。

`cadc_style`：在 DiT-IC 上加入纹理驱动的编码前缩放、解码不逆缩放，未实现完整 CADC 的 ADGIC/BFATC，不能用该名字报告“复现了 CADC 全算法”。

`idea1`：启用语义量化与文本熵条件，使用原 variance-guided 解码，同时附加真实文本。

`idea2`：主量化尺度固定为 1，保持无新增文本熵条件；解码侧启用解码学生、局部 SNR 时间场、局部调制及双路引导。

`joint`：同时启用 idea1 与 idea2。

因此“思路二消融”应在其真实适用路径上做，不能在 joint 的时间场分支里切换一个根本没被使用的原 variance_flow 开关并冒充有效实验。完整作用域表见 `EXPERIMENTS_ZH.md`。

## V2：训练视图、损失防退化与恢复

`augmentation=center, views_per_image=1` 保留原先中心裁剪；`cached_random` 为每张图生成固定数量的确定性随机裁剪/水平翻转/垂直翻转视图。
随机种子由图像内容哈希、crop、视图编号、seed 共同决定，和 worker 分配、epoch、恢复位置无关。
教师观察的是该视图真实图像；缓存键包含完整视图参数，不把旧中心裁剪地图直接贴到另一张裁剪图上。
`cfg.val_manifest` 的教师与验证始终使用中心裁剪。固定有限视图库不是作者无限随机增强的同义词。

加权图像损失使用 `w.detach()`：w 决定保护区域，但学生不能仅仅调低困难区域的 w 来降低这项损失。
地图蒸馏、量化分支等其余路径仍可更新地图网络。water-filling 监督目标内部也停止梯度。

断点中保存训练/验证清单的 SHA256、模型、两个优化器、判别器及其优化器、EMA、所有 rank 的 Python/NumPy/Torch/CUDA RNG。
恢复要求算法配置、世界大小和清单内容不变。`--stop-after` 仅提前停止，不改 cfg.steps，
因此恢复的学习率时间轴与不中断运行一致。`checkpoint-compare` 对实际保存的张量和状态逐项严格比较。
